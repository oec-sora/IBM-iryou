# IBM-iryou - 医療リソース自律調整AI Agent

地域医療向けの最適病院推薦システム（モック版）

## 概要

本システムは、地域医療における救急・紹介患者の最適な病院選定を支援するAI Agentのモックアプリケーションです。AIは判断を提案するのみで、最終判断は必ず人間（医療従事者）が行う設計となっています。

## 機能

### 画面① ダッシュボード
- 地域内の病院一覧をリアルタイム表示
- 各病院の診療科、空き病床数、当直医の有無、救急受入可否を表示
- 診療科フィルターと救急受入可能フィルター機能

### 画面② 救急・紹介依頼入力
- 患者情報（年齢、症状、重症度、希望条件）の入力フォーム
- AIによる最適病院候補の自動提示（上位3施設）
- スコアリングによる推薦順位表示

### 画面③ AI判断根拠表示
- AI推薦理由の詳細説明
  - 距離・アクセス性
  - 空き病床状況
  - 専門医の在籍状況
  - 過去の受入実績
- 人による確認・承認UI
- 推薦の承認または別病院の選択機能

### 画面④ 紹介・交渉支援
- 紹介状の自動ドラフト生成
- 受入依頼文の自動生成
- 編集機能（生成後の内容修正が可能）
- 送信機能

### 画面⑤ 搬送後記録
- 搬送結果の記録（受入成功/拒否/転送）
- 所要時間の記録
- 備考の入力
- 過去の搬送記録の表示
- 記録データは次回AI判断に活用（LocalStorageに保存）

## AI判断ロジック（モック）

システムは以下の要素を総合的に評価して病院をスコアリングします：

1. **診療科マッチング**（30点）- 必要な診療科の有無
2. **救急受入可否**（25点）- 重症患者の場合に重視
3. **当直医の有無**（15点）- 緊急時の対応能力
4. **空き病床数**（20点）- 受入可能性
5. **距離**（15点）- 近いほど高評価
6. **過去の成功率**（最大10点）- 実績データに基づく評価

## 使い方

1. ブラウザで `index.html` を開く
2. ダッシュボードで現在の病院状況を確認
3. 「② 救急・紹介依頼」タブで患者情報を入力
4. AIの推薦を確認し、病院を選択
5. 「③ AI判断根拠」で推薦理由を確認し、承認
6. 「④ 紹介・交渉支援」で自動生成された書類を確認・編集して送信
7. 搬送完了後、「⑤ 搬送後記録」で結果を記録

## 技術仕様

- **フロントエンド**: HTML5, CSS3, Vanilla JavaScript
- **データ保存**: LocalStorage（搬送記録の永続化）
- **リアルタイム更新**: 10秒ごとの病床数自動更新（デモ用）

## モックデータ

以下5つの病院データが含まれています：
- 中央総合病院
- 市民病院
- 東部医療センター
- 北部クリニック病院
- 南部総合医療病院

## 注意事項

- これはモック（デモンストレーション）アプリケーションです
- 実際の医療現場での使用を想定したものではありません
- AIの判断は簡易的なスコアリングアルゴリズムに基づいています
- 実運用には、実際のデータベース接続、セキュリティ対策、医療法規制への対応が必要です
