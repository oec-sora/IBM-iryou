# IBM-iryou

地域医療向け「医療リソース自律調整AI Agent」モックシステム

## 概要

このシステムは、地域医療において病院間の患者紹介・受入を支援するAIエージェントのモック実装です。
AIは判断を提案するのみで、最終判断は医療従事者が行います。

## 機能

### 画面① ダッシュボード
- 地域内の病院一覧をリアルタイム表示
- 診療科、空き病床数、当直医の有無、救急受入可否を一覧表示

### 画面② 救急・紹介依頼入力
- 患者情報（年齢、症状、重症度、希望条件）を入力
- AIが最適な病院候補を複数提示

### 画面③ AI判断根拠表示
- 推薦理由を文章で説明（距離、空き病床、専門医、過去実績）
- 医療従事者が確認・承認するUI

### 画面④ 紹介・交渉支援
- 紹介状ドラフトと受入依頼文を自動生成
- 内容の編集・送信が可能

### 画面⑤ 搬送後記録
- 搬送結果・受入可否・所要時間を記録
- 次回のAI判断に活用

## セットアップ

### 必要な環境
- Node.js 18以上
- npm または yarn

### インストール

```bash
npm install
# または
yarn install
```

## 起動方法

### 開発サーバーの起動

```bash
npm start
# または
yarn start
# または
npm run dev
# または
yarn dev
```

起動後、ブラウザで http://localhost:5173/ にアクセスしてください。

### ビルド

```bash
npm run build
# または
yarn build
```

## 使用技術

- React 19
- TypeScript
- Vite

## 注意事項

- これはモック実装です。実際のシステムとして使用する場合は、セキュリティ、データ管理、バックエンド実装などの追加開発が必要です。
- AIの推薦は参考情報であり、最終判断は必ず医療従事者が行ってください。
- 緊急性が高い場合は、まず119番へ連絡してください。
